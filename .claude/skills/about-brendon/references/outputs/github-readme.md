# Output guide: GitHub profile README

The README in the `brendonotto/brendonotto` repository renders at the top of github.com/brendonotto. Readers arrive from a PR, a LinkedIn link, or a recruiter's search and spend about fifteen seconds. Optimize for a fast, accurate first impression, then one click onward.

## Structure (keep to roughly 40–70 lines of Markdown)

1. **Greeting + one-line identity.** `# Hi, I'm Brendon 👋` then one sentence: title, company, what the Architecture team does. Call it "the Architecture team" (not "Platforms/Architecture"). Say "working remotely from Minnesota" and do not name the city. One emoji total is enough.
2. **What I do now.** Three to five bullets, present tense, each a concrete responsibility or current project: Montage, AI adoption across the department, API standards, React/Material UI platform. Lead with the most impressive scope.
3. **How I got here.** Two or three sentences of the origin story (Communication Studies → insurance sales → install tech → engineer). This is what makes the README memorable.
4. **Stack.** A short line or compact list: daily stack, then "exploring" (Rust, Elixir, OCaml). Skip legacy tech he no longer wants to work in. Shields.io badges are optional; if used, keep to one row and only for the daily stack.
5. **How I work.** Three or four of his principles as short bullets. Use his wording.
6. **Outside work.** One line: hobbies, BJJ, Oliver.
7. **Links.** Website, LinkedIn, X, YouTube. Make the website the first link. No email address on the README; it draws spam and newsletter sign-ups. LinkedIn and X are the contact routes.

## Things to avoid

- GitHub stats widgets and contribution graphs. His public GitHub is thin, and a stats card would advertise that.
- "Currently learning" lists longer than three items.
- Anything the profile doesn't support (open-source contributions, talks).

## Delivery

Return the full README.md content in a single Markdown file. If asked where it goes: a public repo named exactly `brendonotto` with a `README.md` at the root.
